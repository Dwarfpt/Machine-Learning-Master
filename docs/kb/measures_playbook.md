# Measures playbook

## EXTEND_CONTENT — extend the main story (+50%)
Use when the main-story length is short (a top SHAP risk factor) and the game is a single-player action,
adventure or RPG title. Critics penalise games that feel thin for their price. Needs 2-4 extra months of
production, so it only makes sense well before the release date. Cost 180 k$, manager approval required.
Risk: content added late is often filler; pair it with a playtest to check pacing.

## ADD_MULTIPLAYER — add co-op / multiplayer (up to 4 players)
Use for sports, racing, fighting, party and shooter games where single-player only is a known weakness.
Cost 120 k$, manager approval required. Requires network QA; a broken online mode hurts reviews more than
having none, so combine with extended QA.

## MULTIPLATFORM_PORT — release on one more platform
Use when the publisher has strong results on another platform and the engine already supports it.
Cost 250 k$, manager approval required. Ports done in a rush are a classic source of bad reviews (frame rate,
controls); schedule the port after the main version is stable.

## DELAY_RELEASE_POLISH — delay the release by 3 months for polish
Use for high-risk games where many risk factors are process-related (rushed sequel, licensed game tied to a
movie date, weak publisher track record). Assumed effect: -25% relative risk. Cost 300 k$ and always needs
manager approval because it moves marketing and revenue dates.

## EXTENDED_QA — extended QA / bug-fixing cycle
The default first measure for medium and high risk: bugs and technical problems are mentioned in most
negative reviews. Assumed effect: -15% relative risk. Cost 60 k$, above the 50 k$ approval threshold.

## PLAYTEST_FOCUS_GROUP — playtest with a focus group
Cheap way to find pacing, difficulty and control problems before critics do. Assumed effect: -10%.
Cost 25 k$, starts automatically. Works best 2-3 months before release so findings can still be fixed.

## CRITIC_PREVIEW_PR — critic previews and expectation management
Send preview builds and set realistic expectations (genre, length, target audience). Assumed effect: -5%.
Cost 15 k$, starts automatically. Does not fix the game — use together with a quality measure.

## MONITOR_ONLY — monitoring only
For low-risk games: no spending; the game stays in the monitoring log and is re-scored when its spec changes.
